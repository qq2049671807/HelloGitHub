# 快速开始指南

## 第一次使用

### 1. 确认 Python 已安装

打开命令行/终端，输入：
```bash
python --version
```
应该显示 Python 3.7 或更高版本。

### 2. 安装依赖

在 `password_manager` 目录下执行：

**Windows:**
```cmd
pip install -r requirements.txt
```

**Linux/Mac:**
```bash
pip3 install -r requirements.txt
```

### 3. 启动程序

**Windows:**
- 方法1：双击 `run.bat` 文件
- 方法2：命令行执行 `python password_manager.py`

**Linux/Mac:**
- 方法1：终端执行 `./run.sh`
- 方法2：终端执行 `python3 password_manager.py`

## 5分钟使用教程

### 添加第一个账号

1. 点击 **"添加账号"** 按钮
2. 填写信息：
   - 网站/应用名称：`GitHub`
   - 用户名/账号：`your_username`
   - 密码：`your_password`
   - 备注（可选）：`主账号`
3. 点击 **"保存"**

### 查看密码

- 密码默认显示为 `************`
- 选中账号，点击 **"复制密码"** 按钮
- 密码已复制到剪贴板，可以粘贴使用

### 编辑账号

1. 在列表中选择要编辑的账号
2. 点击 **"编辑"** 按钮（或双击该行）
3. 修改信息后点击 **"保存"**

### 删除账号

1. 在列表中选择要删除的账号
2. 点击 **"删除"** 按钮
3. 确认删除操作

### 搜索账号

1. 在搜索框输入关键词（网站名或账号）
2. 列表自动筛选匹配的结果
3. 点击 **"清除"** 按钮恢复完整列表

## 常见问题

### Q1: 提示缺少模块怎么办？

**错误信息：** `No module named 'PyQt5'` 或 `No module named 'cryptography'`

**解决方法：**
```bash
pip install -r requirements.txt
```

### Q2: 密码忘记了怎么办？

本程序是用来**存储**您的密码，如果您忘记了某个网站的密码，需要通过该网站的"忘记密码"功能找回。

### Q3: 可以在多台电脑使用吗？

可以，但需要复制以下文件到其他电脑：
- `passwords.db`（数据库文件）
- `secret.key`（加密密钥文件）

这两个文件在第一次运行程序后自动生成。

### Q4: 数据安全吗？

- ✅ 密码使用 Fernet 加密算法加密存储
- ✅ 数据存储在本地，不上传云端
- ✅ 只要保护好 `secret.key` 文件，数据就是安全的

### Q5: 如何备份数据？

复制以下两个文件即可：
1. `passwords.db` - 数据库文件
2. `secret.key` - 加密密钥文件

**重要提醒：** 两个文件必须一起备份，缺一不可！

### Q6: 密钥文件丢失了怎么办？

⚠️ 如果 `secret.key` 文件丢失，已存储的密码将**无法解密**，相当于永久丢失。请务必备份此文件！

## 安全建议

1. 🔐 **定期备份**：每周备份一次 `passwords.db` 和 `secret.key`
2. 🚫 **不要分享**：不要将密钥文件分享给任何人
3. 📁 **安全存储**：将密钥文件存储在安全的地方
4. 🔒 **电脑安全**：确保您的电脑有登录密码保护
